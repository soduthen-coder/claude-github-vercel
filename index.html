  1. 필요한 프로그램 준비

    없는 것만 골라서 설치합니다.

  2. 깃허브 로그인

    클로드가 8자리 코드를 보여 줍니다. 열리는 브라우저에 넣고 승인해 주세요.

    직접

  3. 버셀 로그인

    브라우저에서 Continue with GitHub 을 고르면 끝입니다.

    직접

  4. 저장소 만들고 올리기

    결과물을 깃허브에 올립니다.

  5. 인터넷에 공개하고 확인

    주소를 만들고, 실제로 열리는지 확인한 결과와 함께 알려 줍니다.

두 번째부터는 1~3 을 건너뜁니다. 올리는 데 20초쯤 걸립니다.

터미널로 직접 실행하기

터미널 열기

글자로 컴퓨터에게 시키는 앱입니다. 이미 컴퓨터에 들어 있습니다.

  1. 윈도우 — 윈도우 키 를 누르고 git bash 입력
  2. 맥 — ⌘+스페이스 를 누르고 터미널 입력

붙여넣기

윈도우 Git Bash 에서는 Ctrl+V 가 듣지 않습니다. 창 안에서 마우스 오른쪽 버튼을 누르면 붙여넣어집니다. 맥은 ⌘+V 로 됩니다.

올리기

git clone https://github.com/soduthen-coder/claude-github-vercel.git
bash claude-github-vercel/ship.sh --dir "올릴폴더"

윈도우라면 ship.cmd 를 더블클릭해도 됩니다.

그 다음

bash ship.sh --dir 폴더 "메모"   고친 내용 다시 올리기
bash lock.sh 이름 on            나만 보기
bash lock.sh 이름 off           다시 공개
bash down.sh 이름               무엇이 지워지는지 보기
bash down.sh 이름 --yes         실제로 지우기
